# Siftmark 产品与技术设计

状态：已通过需求评审，等待书面规格复核  
日期：2026-08-08  
目标平台：Chrome、Edge、Brave、Arc（Manifest V3）

## 1. 产品定义

Siftmark 是一款本地优先的 AI 智能书签管理器。它以 Chromium 原生书签为唯一事实来源，在不引入云端账户或自建服务的前提下，为书签提供规则整理、AI 分类、重命名、标签、摘要、搜索、审核、归档、回收站、健康检查、迁移和备份能力。

首版采用一次性完整交付策略：内部允许按里程碑建设，但只有全部验收项完成后才视为可交付版本。

### 1.1 产品目标

- 完整覆盖 MarkAI 的书签保存、AI 分类、多模型配置、批量整理、历史、统计、备份、管理器、Popup、悬浮按钮和中英文原功能中的中文使用场景。
- 采用洁净重写，不复用 MarkAI 的代码、文案、Logo 或页面结构。
- 支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages、Gemini `generateContent` 四类模型协议。
- 将不可逆操作改造成可审核、可撤销、可恢复的工作流。
- 在约 10,000 条书签规模下保持可用的搜索、列表和批量操作体验。
- 默认不上传遥测，不建设 Siftmark 服务端，不依赖公共免费模型。

### 1.2 非目标

- 不提供云同步、账号系统或团队协作。
- 不长期保存网页正文，不做完整网页剪藏、划线批注或离线阅读。
- 不做标签页会话管理。
- 不在首版提供英文或其他界面语言。
- 不在首版提交 Chrome Web Store 或 Edge Add-ons，只交付源码、开发者模式构建和可加载 ZIP。
- 不授予开源许可证；第三方依赖、字体及素材保留各自许可证。

## 2. 技术架构

### 2.1 技术栈

- WXT + React + TypeScript
- Manifest V3 Service Worker
- IndexedDB（通过独立 Repository 层访问）
- `chrome.storage.local` 保存轻量配置和敏感配置
- Vitest、fake-indexeddb、Playwright
- TanStack Virtual 处理长列表和树
- Lucide 图标体系
- 本地 Lottie 资源及静态 SVG 回退
- Web Crypto API 处理加密备份

### 2.2 扩展入口

- `background`：任务调度、书签事件、模型调用、定时任务、通知和恢复。
- `manager`：全页三栏管理器、搜索、审核、批量操作、历史和设置入口。
- `popup`：当前页快速保存、进度、撤销和常用入口。
- `options`：模型档案、权限、规则、备份、特殊文件夹、主题和高级设置。
- `content`：当前页元数据/正文提取、敏感页面检测、悬浮按钮和交互反馈。
- `commands`：快速保存等浏览器快捷命令。
- `contextMenus`：保存页面、链接、选中文本以及打开管理器。

### 2.3 领域模块

| 模块 | 职责 | 主要依赖 |
|---|---|---|
| bookmarks | 原生书签读取、移动、排序、冲突检测和事件同步 | Chrome Bookmarks Adapter |
| metadata | 标签、摘要、笔记、健康状态和软删除 | IndexedDB Repository |
| operations | 操作日志、恢复点、撤销和幂等写入 | bookmarks、metadata |
| tasks | 持久化队列、暂停、续跑、取消和 Service Worker 恢复 | IndexedDB、alarms |
| rules | 域名、URL、标题、来源文件夹规则 | bookmarks、settings |
| ai | 协议适配、档案能力、Schema 校验和任务路由 | network、security |
| capture | 当前页提取、脱敏、截图和后台标签页采集 | content、tabs |
| search | 关键词索引、筛选和可选向量检索 | metadata、embeddings |
| health | 重复检测、URL 规范化和失效链接检查 | bookmarks、network |
| backup | HTML/JSON/ZIP/MarkAI 导入导出、校验和加密 | bookmarks、metadata |
| notifications | Toast、应用内通知和浏览器汇总通知 | tasks、storage |

模块只通过公开接口和领域事件通信，不直接跨层访问 Chrome API 或数据库表。

## 3. 数据模型与存储

### 3.1 事实来源

文件夹、标题、URL、同级索引和父子关系只写入 `chrome.bookmarks`。IndexedDB 不复制完整书签树作为第二事实来源，只保存由书签 ID 关联的扩展数据和可重建索引。

### 3.2 `chrome.storage.local`

保存以下轻量数据：

- 模型档案、Endpoint、协议、能力、超时、连接状态和 API Key。
- 主题、信息密度、悬浮按钮、通知、访问统计和权限偏好。
- 特殊文件夹 ID、最近使用文件夹和首次引导进度。
- 小型运行标记；大对象不得写入此存储。

API Key 不使用 `chrome.storage.sync`，不跨设备同步。API Key 以扩展本地存储原值保存，不宣称具备系统钥匙串级加密；设置页必须明确提示这一安全边界。

### 3.3 IndexedDB 对象仓库

| 仓库 | 关键字段 | 保留策略 |
|---|---|---|
| bookmarkMetadata | bookmarkId、summary、tags、confidence、reason、note、health、archive | 随书签存在；删除后软保留 30 天 |
| thumbnailStore | bookmarkId、blob、hash、width、height、createdAt、lastAccessedAt | 默认 200 MB 上限 + LRU 回收 |
| operationLog | operationId、batchId、before、after、idempotencyKey | 默认 30 天 |
| taskQueue | taskId、type、inputSnapshot、profileVersion、state、progress、retryCount | 终态任务保留 30 天 |
| searchIndex | bookmarkId、keywordTokens、embeddingProfile、dimensions、vectorVersion | 可重建；模型切换后渐进重建 |
| notificationStore | notificationId、type、read、createdAt、taskId | 30 天或 500 条 |
| softDeletedMetadata | bookmarkId、payload、deletedAt、originalLocation | 30 天 |
| visitAggregates | bookmarkId、count、lastVisitedAt、dailyBuckets | 最近 90 天聚合 |

### 3.4 同步与冲突

- 监听书签新增、修改、移动、删除和导入事件，执行增量同步。
- 定期运行完整一致性校验，发现孤儿元数据时只生成清理建议。
- 执行 AI 或批量结果前重新读取原生书签；标题、URL、父文件夹或索引发生变化即判定冲突，不覆盖最新状态。
- 原生书签写入使用幂等键，防止 Service Worker 重启后重复移动或重命名。

### 3.5 无痕模式

默认不启用无痕模式。用户在浏览器扩展设置中显式授权后，无痕页面享有完整功能，数据写入同一书签集合和同一数据模型，不保留无痕来源标记，并正常参与搜索、备份和导出。

## 4. AI 模型与调用管线

### 4.1 协议与预置档案

统一支持：

- OpenAI Chat Completions
- OpenAI Responses
- Anthropic Messages
- Gemini `generateContent`

预置 OpenAI、Anthropic、Gemini、DeepSeek、通义千问、智谱、豆包、MiniMax、Ollama 档案。用户可以修改 Endpoint、模型名、API Key 和超时，但不能注入任意 JavaScript、任意请求体或任意响应 JSONPath。

每个档案声明分类、重命名、摘要和 Embedding 能力。档案可保存为草稿，只有最小文本请求、结构化输出探测及可选 Embedding 探测成功后才能启用。

分类、重命名、摘要和 Embedding 可以分别绑定不同档案。任务锁定启动时的档案版本；配置更新只影响新任务。

### 4.2 调用顺序

1. 对输入执行权限、URL 和敏感页面检查。
2. 本地规则按域名、URL、标题和来源文件夹优先匹配。
3. 需要 AI 时提取元数据和最多 12,000 字符的正文片段。
4. 本地脱敏邮箱、手机号、API Key、JWT 和密码字段等常见模式。
5. 将正文包装为明确的不可信数据区，禁止模型执行正文内指令。
6. 通过任务类型选择已启用且具备相应能力的模型档案。
7. 优先使用协议原生结构化输出，统一转换为 Siftmark JSON Schema。
8. Schema 不合法时只允许一次受限修复；仍失败则进入待处理队列。
9. 本地验证标题、文件夹、层级、权限、冲突和 URL 不可变约束。
10. 高置信度且符合规则的单项结果可自动执行，其他结果进入审核。

AI 默认输出：目标文件夹、标题、标签、简短中文摘要、置信度等级和简短理由。外文页面保留原语言标题；标签和摘要使用简体中文。不展示完整模型思考过程，不使用伪精确百分比。

### 4.3 请求队列与失败处理

- 每个模型档案维护独立队列、并发控制和自适应退避。
- 识别 `429`、`Retry-After`、超时、网络错误和配置错误。
- 网络/限流错误最多有限重试两次；配置错误不重试。
- 浏览器异常重启导致结果无法确认时标记“结果未知”，不自动重复计费请求。
- 离线时暂停网络任务，本地搜索、编辑、规则和导出继续可用。
- 用户取消任务时中止可取消请求、不再领取新项；已完成项保留并可撤销。
- 批量任务超过 20 条时显示数量、模型和预计请求次数并二次确认。
- 不设置费用预算或硬限制，但保留请求数、Token、耗时和估算用量历史。

### 4.4 数据最小化

- 网页正文只在当前调用内存中存在，调用结束立即丢弃。
- 不保存完整请求、完整响应或原始正文。
- Embedding 只接收标题、域名、文件夹、标签和 AI 摘要。
- 用户笔记、完整 URL 查询参数和网页正文不发送给 Embedding 模型。
- 访问统计只用于本地排序与清理建议，不发送给模型。

### 4.5 提示词策略

- 分类、重命名和摘要分别使用内置、版本化的默认提示词。
- 高级设置允许用户填写附加规则，而不是替换协议约束、JSON Schema 或安全指令。
- 设置页可以预览最终提示词中由用户控制的部分，并支持一键恢复默认。
- 导入提示词配置前必须展示差异；提示词不具备执行代码、改变 Endpoint 或扩大数据范围的能力。

## 5. 书签工作流

### 5.1 保存

支持保存当前页、链接、所选标签页和当前窗口全部标签页。Popup 一键先保存原始书签，再异步分析；保存动作不被模型或截图失败阻塞。

发现重复 URL 时先显示匹配项，可打开现有项、更新标题/标签/笔记、创建副本或取消。默认不创建重复项。

目标文件夹默认使用最近选择，规则优先，AI 提供建议。AI 优先复用现有文件夹，必要时只在用户指定根目录下创建新文件夹，默认最多 3 层。

### 5.2 审核与批量操作

统一审核工作区包含：待审核、低置信度、冲突、失败、重复和失效。支持逐项审核、批量接受/拒绝、字段级应用和续跑。

批量任务逐项提交；部分失败不回滚成功项。每个变更记录前后状态并支持单项或批量撤销。

### 5.3 删除、归档和特殊文件夹

- 删除先移动到用户指定的 Siftmark 回收站，默认保留 30 天。
- 归档移动到用户指定的原生归档根文件夹，记录原位置，默认从常规视图隐藏但参与搜索。
- 低置信度和未归类项进入待整理箱。
- 首次引导中由用户选择或创建待整理箱、归档和回收站，绑定文件夹 ID 而非名称。
- 特殊文件夹被移动或重命名不影响绑定；被删除后暂停相关功能并请求重新关联。

### 5.4 重复、健康和访问统计

- URL 采用保守规范化：统一协议/主机大小写和默认端口，移除明显追踪参数，保留业务查询参数。
- 重定向只作为重复判断的辅助证据。
- 失效检测区分永久失效、暂时不可达、登录受限和检测受阻，不自动删除。
- 定时检查默认关闭，可选择每周或每月运行。
- 访问统计默认关闭；启用后只保存聚合次数、最近访问和 90 天趋势。
- 长期未访问项只进入清理建议，不自动归档或删除。

## 6. 内容采集、截图与笔记

### 6.1 正文采集

- 当前页只在保存、手动分析或批量整理时按需提取正文。
- 批量整理已有书签需用户明确启用，受限打开后台标签页，限制并发和数量，完成后自动关闭。
- 采集密码页、支付页、内网页面、浏览器内部页和黑名单域名时默认停止正文提取。
- 正文按完整段落截断到最多 12,000 字符，优先保留标题、摘要、开头和结尾。

### 6.2 缩略图

- 保存当前页时自动截取可见区域，最长边缩放至不超过 1280px，以 WebP 质量 0.72 保存；可全局关闭。
- 登录、支付、密码输入和黑名单页面默认不截图；用户显式开启无痕权限后，无痕页面按普通页面规则处理。
- 截图失败不阻塞保存，使用占位图并允许手动重试。
- 缩略图默认在详情侧栏显示，列表预览可选。
- 点击缩略图先打开本地大图预览，再由用户打开网页。
- 不后台刷新；只在保存时生成一次，用户可手动更新。
- 缩略图默认不进入备份；导出时可选并显示预计体积。

### 6.3 笔记

- 支持受限 Markdown，禁用原始 HTML 和脚本。
- 远程图片默认不加载；链接必须由用户点击打开。
- 右键保存选中文本时只创建本地笔记草稿，不自动发送给模型。
- 选中文本默认最多 2,000 字符，超出时本地截断并提示。

## 7. 搜索与索引

默认搜索覆盖标题、URL、文件夹、标签、摘要和笔记，使用规范化词元、中文二元分词、前缀和有限编辑距离进行本地排序，并支持文件夹、域名、标签、状态和时间筛选。

未配置 Embedding 时保留搜索入口并明确使用本地模式。配置后将关键词结果与语义结果融合排序。

Embedding 索引规则：

- 用户启用后异步生成，新书签和修改项进入索引队列。
- 搜索遇到未索引项时可以按需补齐。
- 索引任务支持暂停、续跑、重建和删除。
- 按模型、维度和版本隔离向量。
- 切换模型后旧索引标记过期，新索引渐进重建；完成前降级为关键词或只使用同版本向量。

## 8. 导入、导出与迁移

### 8.1 支持格式

- 浏览器 Netscape Bookmark HTML
- Siftmark 原生 JSON/ZIP
- MarkAI 兼容备份
- CSV 审阅导出

### 8.2 原生备份结构

默认导出用户选定范围的书签、文件夹、标签、摘要、笔记、审核状态和操作历史。带缩略图时使用 ZIP：

```text
backup.zip
├── manifest.json
├── data.json
└── thumbnails/
    └── <bookmark-id>-<hash>.webp
```

`manifest.json` 包含 Schema 版本、导出时间、数据统计、文件清单和校验和。未知字段忽略；未知版本允许查看诊断但拒绝写入。

### 8.3 冲突与加密

- 导入前解析到隔离预览模型，不直接写入书签。
- 按 URL、标题和文件夹匹配冲突，支持跳过、保留、创建副本或合并标签/笔记。
- 默认不删除现有数据。
- 普通配置导出自动脱敏 API Key。
- 完整密钥备份先生成上述 ZIP 字节，再使用 AES-256-GCM 加密为 `.siftmark-backup` 容器；PBKDF2-SHA-256 使用随机 Salt、600,000 次迭代和随机 Nonce，密码不写入文件。
- 备份清单和文件内容使用 SHA-256 校验和。
- 高风险重置和全量覆盖必须显示影响数量、提供备份入口并要求输入确认词。

## 9. 界面与品牌

### 9.1 品牌

- 名称：Siftmark
- 描述：AI 智能书签管理器
- 标志：筛选漏斗 + 书签切口
- 结构色：`#111111`
- AI/品牌强调色：`#B7FF36`
- 荧光绿只用于品牌和 AI 活动态；普通命令使用中性色和标准语义色。

概念预览保存在 `design/previews/`，最终图标必须重新绘制为确定性 SVG，并验证 16/48/128px 识别度。

### 9.2 版式

- 全页管理器宽屏采用文件夹树、书签列表、详情/审核侧栏三栏布局。
- 中等宽度收起详情；窄屏使用抽屉或弹层。
- 提供舒适/紧凑两档，默认舒适；正文和控件以 13–14px 为基准。
- Noto Sans SC 与 Space Grotesk 使用本地可变字体，不调用在线字体服务。
- 网站图标优先通过浏览器能力获取并本地缓存，不调用第三方 Favicon 服务。

### 9.3 动效与无障碍

- 原创 Lottie 状态：待机 Logo、AI 分析中、任务完成、任务暂停/失败。
- 动画只集中在品牌和 AI 状态区；书签列表、编辑控件和文本保持稳定。
- 本地按需加载，提供文本状态和静态 SVG/PNG 回退。
- 系统启用减少动态效果或设备性能不足时关闭非必要动画。
- 以 WCAG 2.2 AA 为目标，覆盖键盘导航、焦点、语义标签、屏幕阅读器状态和色彩对比。

### 9.4 主要交互

- 管理器：三栏、虚拟列表、详情侧栏、统一审核队列、拖放及键盘等价操作。
- 列表支持手动排序及名称、域名、创建时间、更新时间、访问时间、健康状态和 AI 置信度排序，并按文件夹记忆排序方式。
- 书签右键菜单包含打开、移动、AI 分析、审核、标签、导出、复制链接和回收站；文件夹额外包含新建子文件夹和健康检查。
- Popup：快速保存、后台进度、撤销和管理器入口。
- 悬浮按钮：默认关闭，可全局启用并按域名隐藏。
- 右键菜单：保存页面、链接、选中文本和打开管理器。
- 默认只注册一个快速保存快捷键，其他命令由用户在浏览器扩展快捷键页配置。
- 系统通知只显示任务数量和状态汇总；标题、URL 和错误详情只在管理器内显示。

## 10. 权限、隐私与诊断

### 10.1 权限

扩展使用书签、存储、标签页、脚本、上下文菜单、快捷命令、闹钟和 `<all_urls>` 等能力。`notifications` 放入 `optional_permissions`，只在用户启用后台任务通知时请求。由于 Manifest 中的必需主机权限会在扩展安装前展示，无法由扩展自己的运行时页面提前解释，因此权限用途必须同时出现在安装说明/README 和首次引导中。拒绝或撤销网页权限后，本地书签管理仍应可用。

浏览器通知权限仅在用户启用后台任务通知时请求；拒绝后使用应用内通知。

### 10.2 隐私

- 不上传遥测、崩溃报告或使用分析。
- 本地诊断包必须脱敏，由用户主动导出。
- 系统通知不包含书签标题、URL 或详细错误。
- 危险协议默认禁止：`javascript:`、`data:`；`file:`、浏览器内部页和自定义协议需明确确认并受浏览器限制。
- 不调用第三方 Favicon、字体、动画或分析 CDN。

### 10.3 重置

设置页提供分级重置：缓存/缩略图、AI 元数据和索引、历史和任务、模型配置、全部 Siftmark 数据。任何级别默认都不删除浏览器原生书签。

## 11. 首次引导

向导可跳过并可中途继续，包含：

1. 权限与隐私说明。
2. 待整理箱、归档和回收站位置。
3. 悬浮按钮开关。
4. 模型档案配置和连接测试，可跳过。
5. 用户主动选择 MarkAI 备份文件并预览迁移。
6. 对现有书签执行只读扫描，展示数量、重复、健康和待整理范围。

未配置模型时，本地管理、规则、搜索、备份、去重和链接检测仍可使用。

## 12. 通知与任务体验

- 普通操作使用 Toast。
- 应用内通知中心保留 30 天、最多 500 条，支持已读、筛选和清空。
- 长任务完成、暂停和严重失败可以发送浏览器汇总通知。
- Service Worker 重启后从 IndexedDB 恢复任务。
- 任务进度以已完成、待处理、失败和未知结果数量呈现。
- 模型配置版本删除、权限撤销或特殊文件夹缺失时暂停任务并给出明确恢复动作。

## 13. 测试与质量门禁

### 13.1 自动化

- 类型检查、Lint 和生产构建。
- 单元测试：URL 规范化、规则、Schema、加密、导入、冲突、队列状态机。
- IndexedDB 测试：迁移、软删除、操作日志、任务恢复、索引版本。
- Chrome API 集成测试：事件同步、移动、排序、回收站、撤销和权限降级。
- Playwright 扩展测试：Popup、管理器、设置、保存、审核、备份、恢复和首次引导。

### 13.2 浏览器与视觉

- Chrome 和 Edge 执行人工验收清单。
- 浅色/深色、舒适/紧凑、宽屏/中屏/窄屏截图检查。
- Lottie 必须验证非空、可见、停止回退和减少动态效果。
- UI 不得出现文字溢出、不可达控件、重叠、空白视图或无焦点状态。

### 13.3 性能目标

- 10,000 条书签使用虚拟化渲染，不一次性挂载完整树和列表。
- 首次扫描、批量整理和索引重建必须分片、可暂停、可续跑。
- 缩略图、向量和通知都有明确容量/数量上限。
- Popup 保存操作不等待截图、AI 或索引完成。

## 14. 内部实施里程碑

1. **工程基础**：WXT、React、TypeScript、Manifest、测试框架、领域类型、适配层。
2. **数据基础**：IndexedDB、书签同步、操作日志、回收站、归档、任务队列。
3. **AI 管线**：四类协议、档案、能力探测、规则、Schema、审核和错误恢复。
4. **核心界面**：管理器、Popup、Options、内容脚本、右键菜单和快捷键。
5. **增强能力**：搜索、Embedding、截图、健康检查、访问统计和通知。
6. **迁移与安全**：HTML/JSON/ZIP/MarkAI、冲突预览、加密备份、首次引导和重置。
7. **交付**：完整自动化、性能和视觉验收、用户/开发文档、开发者模式 ZIP。

每个里程碑使用中文 Conventional Commits 提交。最终交付前所有门禁必须通过。

## 15. 完成定义

Siftmark 只有同时满足以下条件才视为完成：

- 全部上述功能已实现，不以静态占位、演示数据或未连接按钮代替。
- Chrome 和 Edge 可通过开发者模式加载生产构建。
- 所有自动化测试和质量门禁通过。
- 关键工作流完成真实扩展端到端验收。
- 模型档案至少对四类协议各完成一个可替换测试桩验证；真实供应商调用由用户 API Key 决定。
- MarkAI、HTML 和 Siftmark 备份可预览、导入、冲突处理和恢复。
- 用户手册、开发指南、架构说明、模型协议、备份恢复、权限隐私和测试文档齐全。
- 生成可加载 ZIP，并记录构建版本、Git 提交和校验和。
