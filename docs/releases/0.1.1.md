# Siftmark 0.1.1

发布日期：2026-08-10  
发布类型：Chromium Manifest V3 开发者模式 ZIP

## 主要变更

- 补齐 AI 模型配置、能力分配与任务路由。
- 将收藏流程重构为一键智能书签工作流。
- 设置改为独立标签页，支持智能收藏偏好与原生收藏接管。
- 接通本地 AI 用量计量。
- 原生 `Ctrl+D` 收藏时显示处理中提示；成功后显示实际保存路径，失败时显示原因。
