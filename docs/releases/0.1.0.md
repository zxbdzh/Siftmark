## 功能范围

- 以 Chromium 原生书签树作为唯一书签事实源，支持 Popup、右键菜单、快捷键和悬浮按钮保存。
- 支持文件夹、搜索、健康状态、字段级 AI 审核、归档、回收站、撤销和可恢复后台任务。
- 支持 OpenAI Chat/Responses、Anthropic Messages、Gemini generateContent 四类协议适配。
- 支持 Siftmark JSON/ZIP、浏览器 HTML、MarkAI JSON 和加密完整配置的预览、导入与导出。
- 支持浅色/深色、舒适/紧凑、本地字体、Lottie 状态动画和 reduced-motion 静态回退。
- API Key 仅保存于 `chrome.storage.local`；无遥测、远程字体或远程图标资源。

## 已知限制

- 本产物未签名且未提交 Chrome Web Store 或 Microsoft Edge Add-ons，只用于开发者模式加载。
- 普通备份主动排除 API Key 和模型档案；需要迁移完整模型配置时必须使用加密完整配置。
- 网站访问设为“点击时”或撤销后，本地书签管理、搜索和备份仍可用，但页面分析、正文采集和缩略图会降级。
- 可能计费的远程分析任务在 Service Worker 中断后不会自动重发，会以 `unknown` 状态等待用户处理。

## 安装与回滚

1. 校验 ZIP 的 SHA-256，然后解压到独立目录。
2. 在 `chrome://extensions` 或 `edge://extensions` 开启开发者模式并选择“加载已解压的扩展程序”。
3. 升级或回滚前先导出普通备份；需要迁移 API Key 时另外导出加密完整配置。
4. 回滚时卸载当前扩展并加载保留的旧版本解压目录。卸载不会删除 Chromium 原生书签；重新导入备份可恢复扩展元数据和设置。
