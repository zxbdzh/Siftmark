# Siftmark 0.1.4

发布日期：2026-08-18  
发布类型：Chromium Manifest V3 扩展

## 主要变更

- 完善 Agent 睡眠回顾反馈闭环：支持跨批次累积证据，并保留每条学习记忆的真实来源归属。
- 统一学习记忆与候选目录的路径语义，兼容旧版根路径记忆，并使用目录 ID 消除同名目录歧义。
- 在 Agent 历史中展示睡眠记忆的命中、采用和避开结果，设置页新增采用记录入口。
- 为模型请求补充超时、可重试错误处理、档案级限流与自动重试，降低瞬时网络和配额波动造成的失败。
- 统一发送给模型的书签内容安全边界，对不可信页面文本进行长度限制和提示注入边界标记。
- 强化 Anthropic 与 Gemini 连接探针，并修正分析任务失败状态和模型错误文案。

## 质量验证

- TypeScript 类型检查通过。
- ESLint 全仓检查通过。
- Vitest `101` 个测试文件、`341` 项测试通过。
- WXT Chromium MV3 生产构建通过。
- Agent 睡眠闭环扩展 E2E 两项场景通过；本机 Playwright 在用例完成后的 Chromium 清理阶段出现超时，发布工作流会在独立 Linux 环境重新执行完整 E2E。

## 已知限制

- 睡眠回顾仍受 12 小时冷却和单批处理上限约束，这是控制模型成本的既有策略。
- 多个浏览器根目录下存在完全相同的逻辑路径时，模型输入可能出现重复显示路径；采用结果已通过目录 ID 防止误判。
