# Siftmark 用户指南

## 首次设置

设置页依次显示五步引导：权限与隐私、特殊文件夹、可选模型、迁移数据和只读扫描。进度保存在本机，每一步都可跳过。

建议至少绑定“待整理箱”。当 AI 方案需要新目录、置信度不足、发现重复或存在其他风险时，Siftmark 会先把已经保存的书签移到这里，等待允许或拒绝。归档与回收站仍用于管理器中的长期整理和软删除。

在“AI 模型”中保存并验证模型后，可分别分配分类、重命名、摘要、语义检索和“收藏 Agent”任务。未单独分配收藏 Agent 时使用分类模型。

## 快速收藏

主入口是浏览器原生收藏：

- `Ctrl+D`（macOS 为 `Command+D`）或地址栏星标。
- `Ctrl+Shift+S`（macOS 为 `Command+Shift+S`）保存当前页。
- 页面右键菜单保存当前页或链接。

所有入口都遵循同一顺序：先创建原生书签，再进行 AI 分析。模型未配置、网络超时或响应无效都不会删除已经收藏的页面。

Siftmark 不提供常驻网页按钮。工具栏 Popup 也不是保存入口，它只显示待处理队列和最近结果。

## 自动整理与风险审批

安全方案会自动移动到已有目录、按设置缩短标题并写入本地标签和摘要。在“智能收藏”中可设置 AI 单次最多补建 1–5 级目录，并指定优先推荐的目录深度（不计算“书签栏”根目录）。关闭新目录后，AI 只会选择已有目录。只要方案包含新目录，无论一级还是多级都会进入审批。

联网搜索与页面识图默认开启。使用 OpenAI Responses 时，Siftmark 会把当前可见区域的临时 JPEG 截图作为 `input_image` 发送，并要求模型实际调用 `web_search`；可在“智能收藏”中分别关闭。登录、支付、密码、内网和已屏蔽域名页面不会截图。

以下情况会请求审批：

- 新建一级或多级目录。
- 目标不明确、置信度不足或页面信息不足。
- 精确重复、相似收藏或本地规则冲突。
- 标题变化过大、目标是特殊文件夹或书签状态已被外部修改。

风险方案会自动显示网页浮层，列出目标位置、新目录和建议标题：

- “允许”：本地执行当前方案。
- “拒绝”：不执行方案，书签保留在待整理箱或当前原位。
- “与 Agent 调整”：打开 Side Panel 修改目录或标题，再允许或拒绝。

精确重复在批准后合并到现有书签并移除临时副本；相似项只提示，不自动合并。执行前会重新校验书签与目录，检测到变化时不会覆盖外部修改。

## 与收藏 Agent 对话

Side Panel 固定显示当前方案、目录路径、风险原因和本次会话消息。自动整理完成后仍可从最近结果继续调整，Agent 会以书签当前实际位置作为新起点。

普通允许、拒绝和调整不会自动成为长期规则。你可在设置开启“本地学习”，授权从此后的明确操作积累短期证据；两个不同书签的一致反馈才会形成可复用经验。明确说“以后这类都放到 Agent 目录”仍可直接建立固定规则，在“Agent 固定规则”中查看和删除。

普通待处理会话在 7 天后转为过期；可重试的失败会话继续保留，方便用户补充要求或重试。允许、拒绝、撤销或过期都不会自动清空消息。完整会话记录保存在当前浏览器的扩展 IndexedDB，供设置中的“Agent 记录”查看和删除单条已结束记录；Popup 可清空全部已结束记录。记录不会上传到 Siftmark 服务；启用 WebDAV 全量同步后，会以加密历史记录同步，会保留到用户主动删除、执行“全部 Siftmark 数据”重置，或卸载扩展时通常一并清除。删除 Agent 记录不会同时删除已经学习到的归类偏好。

Side Panel 和 `Ctrl+D` 触发的网页浮层会按时间线显示页面准备、候选目录、截图识别、联网搜索、AI 方案、风险检查和本地执行。每一步可显示输入数量、工具确认、输出摘要和耗时。这些是可审计的操作记录，不是模型的私密思维链；提示词、网页正文、截图和原始模型响应不会写入时间线。

## 本地学习与复盘

在设置的“Agent 本地学习与复盘”中开启“本地学习”，只记录此后在 Siftmark 中的收藏确认、拒绝、撤销、手动分类和检索后选择。学习数据始终留在本机，不发送给模型，不消耗模型额度。单次操作只是短期证据，至少两个不同书签的一致反馈才会形成经验；证据保留 30 天，经验 90 天未更新则停止采用。

每条经验显示依据、来源 ID、置信度、更新时间和有效状态。展开“查看来源与纠正”可改目标目录或改成避开该目录，也可删除单条记忆。暂停学习会同时停止积累与采用；“清空学习数据”会删除证据、经验和未执行的主动方案，原生书签、固定规则和撤销记录保留，旧任务不会复活已清空的记忆。

“现在回顾”或单独授权“空闲时主动检查”可发现现有位置与经验不一致的书签。自动检查每 12 小时最多一轮，扫描最多 200 个书签，最多保留 3 个方案。点击“确认执行”后才移动；“拒绝建议”用于修正经验；执行后可“撤销此方案”。后台中断后恢复方案或显示具体冲突原因，提供撤销已记录操作、结束方案的入口。原有收藏和全量整理仍按既有模型与审批边界运行。

## Popup 与撤销

Popup 的“待处理”区域显示正在分析、等待批准、执行中或失败的收藏；可直接允许、拒绝、打开 Agent 或重试。“最近结果”显示自动整理、已批准、已拒绝和已撤销的记录。

自动或批准执行后可撤销最近的本地操作批次。撤销覆盖该批次中的目录创建、移动、改名、元数据和精确重复处理，不会回滚其他时间发生的外部修改。

## 管理书签

管理器提供文件夹树、虚拟化书签列表和详情栏。标题、URL、父文件夹与顺序直接写入 Chromium 原生书签；标签、摘要、笔记、健康状态和索引保存在扩展本地数据库。

- 列表支持标题、域名、创建/更新时间、访问、健康和置信度排序。
- 书签菜单可打开、移动、请求分析、归档、回收或导出。
- 文件夹菜单可新建子目录、启动健康检查和执行批量操作。
- 顶部搜索覆盖标题、URL、路径、标签、摘要和笔记；Embedding 不可用时自动回退本地搜索。

### 全量 AI 整理

点击“备份并整理全部”，先查看可整理与跳过数量，选择本次使用的已验证分类模型。点击“备份并生成方案”后，扩展先下载完整 HTML；成功后把全部可整理书签的 ID、标题和脱敏网址分批发给所选模型，不读取网页正文，也不把旧目录作为分类候选。

“并发批次”可选 1–4，默认 2；只影响本次任务。分析过程显示通读、合并、归属和相似复核各批次的等待、运行、重试、完成或失败状态。每批最多 80 条，较长的标题与网址可能让批次提前拆分；并发分析不会提前创建目录或移动书签。

同 URL 去重只按原始网址完全相等分组，每组向模型发送一份，默认保留最早收藏，也可在方案预览改选。确认方案且保留项成功归位后，才将其他副本移入回收站。模型发现的相似项默认全部保留，可通过“审核相似项”稍后处理。

不合格的相似配对（未知书签、候选外配对、重复配对或同 URL 副本）不会写入审核记录；过程窗口显示忽略数量，已通过校验的分类方案可以继续确认。目录结构和全部书签归属仍须完整通过校验。

分类方案显示最多三级目录、各类书签数量、预计新增目录与移动数量。查看分类及书签明细后，点击“确认并移动”才执行；“取消，不移动”保留原有结构和下载的备份，但模型请求与已消耗的额度无法撤回。新分类直接放在书签栏，相同路径会复用，不同名称可能新增；旧目录及空目录均不删除。原标题、网址、笔记与健康记录保持不变。

整理期间保持管理器页面打开。隐藏过程窗口不会停止任务，关闭管理器会中断后续处理；HTML 备份可用于恢复，但本次全量整理不支持自动撤销已经完成的创建和移动。

分析失败后点击“重试失败批次”，可复用本次任务已完成且校验有效的结果。重新打开管理器后，在“备份并整理全部”中点击“继续上次失败的批次”。续跑会重新下载当前书签的完整 HTML 备份；内容、模型或最终分类树变化时，受影响批次需要重新分析。失败原因和各批次状态可通过“复制诊断”反馈，不包含 API Key、完整提示词或原始响应。

## 模型、规则与隐私

模型档案包含协议、Endpoint、模型、API Key、超时和能力。Endpoint 支持 HTTP 与 HTTPS，其他协议拒绝。API Key 默认以原值保存在当前浏览器扩展本地存储；启用 WebDAV 全量同步后随配置加密同步到其他设备。HTTP 模型端点会明文传输认证与请求内容。

WebDAV 全量同步和 Windows 自动更新见 [使用说明](webdav-and-updates.md)。

新建或修改连接后点击“验证并保存”，成功才更新可用配置，失败则保留原配置与任务分配。仅改名称可直接“保存配置”；草稿尚不可用于 AI 任务。“设为所选任务默认”只在配置已保存且连接验证有效时可用。

收藏 Agent 发送模型前会移除 URL 的用户名、密码、查询参数和片段，正文最多 6,000 字符。不会发送完整书签库、私密笔记或无关会话。模型只能生成方案，不能直接调用浏览器 API。

“整理规则”可按域名、URL 前缀、标题和来源目录移动、加标签、跳过 AI 或送入待整理箱。“禁止读取页面正文”列表只阻止指定网站的正文采集，不阻止原生书签保存。

## 备份、重置与常见问题

备份支持 Siftmark JSON/ZIP、浏览器 Bookmark HTML 和 MarkAI JSON。普通备份移除 API Key；包含密钥时必须使用密码导出加密 `.siftmark-backup`。导入始终先显示预览和冲突计划。

分级重置可清理缩略图、AI 元数据与索引、历史任务或模型配置。“全部 Siftmark 数据”要求输入 `重置 Siftmark`，所有范围都保留 Chromium 原生书签。

**原生收藏后没有自动整理**：确认“接管浏览器原生收藏”已开启，并为分类或收藏 Agent 分配已验证模型。

**没有出现网页审批浮层**：安全方案会直接自动执行；也可打开 Popup 查看结果。若风险项只出现在 Popup，检查该网站的扩展访问权限。

**模型任务失败**：确认协议、Endpoint、模型名和 API Key，并点击“验证并保存”。网络失败最多手动重试两次。

**归档、回收或风险暂存不可用**：在“特殊文件夹”重新绑定未配置或已删除的原生目录。

**需要彻底重新开始**：先导出备份，再执行“全部 Siftmark 数据”重置。卸载扩展通常会删除扩展本地数据。
