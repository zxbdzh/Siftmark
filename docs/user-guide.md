# Siftmark 用户指南

## 首次设置

打开扩展的“选项/设置”页后，Siftmark 会按顺序显示六步引导：权限与隐私、特殊文件夹、网页悬浮按钮、可选模型、迁移数据、只读扫描。选择“跳过此步”不会阻止后续使用；进度保存在本机，可在下次打开时继续。

建议先绑定三个原生文件夹：

- 待整理箱：接收本地规则无法确定的位置。
- 归档：保存不需要出现在常规视图但仍参与搜索的书签。
- 回收站：替代直接删除，默认 30 天后由后台任务清理。

绑定依据是文件夹 ID，移动或重命名不会失效；删除文件夹后相关操作暂停，需在设置中重新绑定。

## 保存当前页面

1. 打开要保存的 HTTP/HTTPS 页面。
2. 点击 Siftmark 工具栏图标。
3. 在“保存到”中选择原生文件夹。
4. 点击“保存书签”。

原生书签会先创建，AI、截图或网络失败不会回滚保存。成功状态出现后可“撤销最近保存”。如果 URL 已存在，Popup 默认保留现有项，也可更新现有标题或明确创建副本。

Popup 下方的标签页批量保存会去除同批重复 URL，并在完成后提供批量撤销。超过 20 项的批量 AI 操作会要求二次确认。

还可使用：

- `Ctrl+Shift+S`（macOS 为 `Command+Shift+S`）快速保存当前页。
- 页面右键菜单保存页面或链接。
- 选中文字后右键“保存选中文本为笔记”；最多保留 2,000 字符，只生成本地草稿。
- 在设置中启用悬浮按钮；可按网站隐藏，并可重置隐藏列表。

## 管理书签

点击 Popup 的“打开管理器”。宽屏显示文件夹、书签列表和详情三栏；中窄屏通过抽屉访问折叠区域。

- 在文件夹树选择范围。
- 在列表选择书签，右侧编辑标题、标签、摘要和笔记。
- 书签菜单可打开、移动、请求 AI 分析、加入审核、导出、复制链接、归档或移入回收站。
- 文件夹菜单可新建子文件夹、启动健康检查或执行特殊文件夹操作。
- 排序支持手动、标题、域名、创建/更新时间、最近访问、链接状态和 AI 置信度，并按文件夹记忆。

标题、URL、父文件夹和顺序直接写入 Chromium 原生书签。执行变更前若检测到外部修改，Siftmark 会报告冲突而不是覆盖新状态。

## 搜索与筛选

顶部搜索覆盖标题、URL、文件夹路径、标签、摘要和笔记，支持中文分词、前缀和有限容错。未配置 Embedding 时状态显示“本地搜索”。

配置并启用具备 `embed` 能力的档案后，Siftmark 将语义结果与本地结果融合。向量按模型、版本和维度隔离；切换模型期间可以继续使用本地关键词结果。

## AI 审核

模型建议不会直接改变 URL。建议包含目标文件夹、标题、标签、摘要、置信度和简短理由。

1. 在管理器选择“审核”。
2. 查看来源快照与建议值。
3. 只勾选需要应用的字段。
4. 选择“应用所选字段”或拒绝建议。

低置信度、冲突、无效 Schema、模型失败、重复和健康问题会留在审核/待处理流程。浏览器在模型请求中断时把结果标为“未知”，不会自动重复可能计费的调用。

## 模型档案与规则

在设置的“模型档案”选择预置或自定义配置，填写名称、协议、Endpoint、模型、API Key、超时和能力。先“保存草稿”，再“测试连接”；只有所声明能力全部通过后才能“启用已验证档案”。

Endpoint 必须使用 HTTPS，只有 `localhost`、`127.0.0.1` 或 `[::1]` 允许 HTTP。API Key 只保存在此浏览器的扩展本地存储中。

“整理规则”按优先级匹配域名、URL 前缀、标题包含和来源文件夹，可移动到文件夹、添加标签、跳过 AI 或送入待整理箱。本地规则先于模型执行。“AI 附加规则”只补充偏好，不能改变安全约束、Endpoint 或输出 Schema。

## 缩略图、健康与统计

保存当前可见页面时会异步生成本地缩略图。密码输入、支付、受限协议或黑名单页面会停止采集；失败不影响书签，可在详情页重试。

健康检查区分正常、临时不可达、永久失效、登录受限和检测受阻，不自动删除。定时检查默认关闭，可设每周或每月及指定文件夹范围。

访问统计默认关闭。启用后只保存本地聚合次数、最近访问和 90 天日桶；清理建议不会自动归档或删除。

## 通知与无痕模式

应用内通知不需要额外权限。开启“后台任务汇总通知”时浏览器会请求可选 `notifications` 权限；系统通知只显示任务状态和数量，不显示标题或 URL。

无痕模式必须在浏览器扩展详情页手动允许。启用后使用同一原生书签和本地扩展数据，不保存“来自无痕”的标记。

## 备份、导入和重置

“备份与迁移”可选根文件夹范围，导出 JSON 或 ZIP；缩略图默认不导出。普通备份会移除 API Key。包含密钥时必须设置密码并导出 `.siftmark-backup`。

导入文件始终先在本地解析、校验并显示预览。选择目标文件夹，为冲突选择跳过、保留、创建副本或合并，再确认写入。详细格式和恢复步骤见 [备份与恢复](backup-and-restore.md)。

“重置”先显示记录数和估算体积。可单独清理缩略图、AI 元数据与索引、历史与任务或模型配置；“全部 Siftmark 数据”要求输入 `重置 Siftmark`。所有范围都保留原生书签。

## 常见问题

**保存按钮不可用**：等待 Popup 读取当前标签页，并选择有效目标文件夹。`chrome://`、`edge://`、`javascript:` 和 `data:` 页面不能作为普通网页保存/采集。

**模型档案无法启用**：确认模型名、API Key、协议和 Endpoint；重新测试连接。代理服务必须兼容所选协议的请求与结构化 JSON 响应。

**页面分析或缩略图不可用**：在扩展详情中检查网站访问权限；密码/支付页面和用户黑名单按设计会阻止采集。

**归档或回收按钮禁用**：在“特殊文件夹”重新绑定已删除或未配置的文件夹。

**导入暂停**：修复最后一项提示的问题后选择“继续上次导入”。导入前创建的恢复点保留在本机。

**需要彻底重新开始**：先导出备份，再使用“全部 Siftmark 数据”重置。卸载扩展通常会删除扩展本地数据，因此卸载前必须另存备份。
