# 权限与隐私

## 隐私摘要

Siftmark 没有账号、遥测、崩溃上报、使用分析或自建服务端。原生书签和扩展数据保存在当前 Chromium 配置中；只有用户启用模型任务时，最小化后的内容才直接发送到用户配置的 Endpoint。

## Manifest 权限

| 权限            | 必需性       | 用途与降级                                                                     |
| --------------- | ------------ | ------------------------------------------------------------------------------ |
| `bookmarks`     | 必需         | 读取/创建/修改/移动原生书签，作为唯一事实源；无此权限产品核心不可用            |
| `storage`       | 必需         | 使用 `chrome.storage.local` 保存设置、引导、模型档案和 API Key                 |
| `tabs`          | 必需         | 读取当前/窗口标签页、批量保存、确认活动页及捕获当前可见页面                    |
| `scripting`     | 必需声明     | 在用户获准的网页上下文运行 Siftmark 打包脚本，支持按需采集；不执行远程代码     |
| `contextMenus`  | 必需         | 注册保存页面、链接、选中文本和打开管理器入口                                   |
| `alarms`        | 必需         | 周期唤醒任务、回收站清理和用户启用的健康检查                                   |
| `<all_urls>`    | 必需主机权限 | 内容脚本覆盖 HTTP/HTTPS 页面、按需采集/截图，并直接访问用户配置的模型 Endpoint |
| `notifications` | 可选         | 用户开启后台汇总通知时才请求；拒绝后使用应用内通知                             |

快捷命令由 manifest `commands` 声明，不是独立权限。`<all_urls>` 是安装时提示的必需主机权限，扩展自身无法在安装提示出现前展示页面，因此 README 同时提前解释其用途。

撤销特定网站访问后，本地书签树、详情编辑、规则、本地搜索、导入导出和重置仍可用；该网站的正文分析、内容脚本和缩略图不可用。Chrome/Edge 对必需主机权限的撤销方式与行为可能随版本变化。

## 本地存储

- 原生书签：`chrome.bookmarks`。
- 模型档案与 API Key：仅 `chrome.storage.local`，不使用 sync。
- 元数据、缩略图、任务、操作、索引、通知、用量和恢复点：扩展 IndexedDB。
- API Key 在浏览器扩展存储中是本地原值，不具备系统钥匙串、TPM 或操作系统账户级加密保证。能读取解锁浏览器配置或控制扩展进程的主体可能获取它。

设置列表只显示掩码；日志和诊断不得输出认证 Header 或 Key。普通备份删除 Key；完整密钥备份必须由用户密码使用 AES-256-GCM 加密。

## 模型数据流

触发保存/分析后，Siftmark 可能向已启用档案发送：页面标题、URL、当前文件夹路径、描述、最多 12,000 字符的正文片段和用户填写的附加规则。

发出前在本地替换常见 API Key、JWT、Bearer Token、密码字段、邮箱和中国大陆手机号。正文被标记为不可信数据，不能改变系统指令、Schema、Endpoint 或权限。

正文只在当前请求内存中存在，请求结束即丢弃；不写入 IndexedDB、storage、日志或备份。Siftmark 不控制第三方模型服务商的日志、训练、地域和保留政策，用户应自行审阅供应商条款。

Embedding 只应使用标题、域名、文件夹、标签和摘要等索引文档，不发送原始正文或完整用户笔记。向量留在本地 IndexedDB，并按档案版本隔离。

## 页面与缩略图

密码输入页、支付页、浏览器内部页、受限协议、内网页面和用户黑名单可阻止正文或截图。截图仅捕获用户当前可见区域，最长边不超过 1,280px，转为本地 WebP；失败不阻止保存。缩略图不后台刷新，默认不进入备份。

Siftmark 不调用第三方 Favicon 服务、远程字体、远程动画、CDN 或分析脚本。字体、图标和 Lottie 均随扩展打包。

## 通知、统计与无痕

系统通知只显示任务类型、状态和数量，不显示书签标题、URL、正文或详细错误。应用内通知详情只存在于扩展本地数据库。

访问统计默认关闭；启用后保存本地次数、最近访问和 90 天日桶，不发送给模型或 Siftmark 服务。

manifest 使用 `incognito: spanning`。默认未获得无痕授权；用户必须在扩展详情页显式开启。开启后无痕和普通窗口共享原生书签与扩展数据，不保存无痕来源标记，因此不要把该功能当作隔离容器。

## 保留与删除

- 通知：30 天或最多 500 条。
- AI 用量：90 天或最多 1,000 条。
- 访问日桶：最近 90 天。
- 回收站：默认 30 天后清理；特殊文件夹未绑定时任务暂停。
- 搜索索引和缩略图可随时单独清理并重建/重新捕获。

设置中的分级重置只删除 Siftmark 扩展数据，永不删除原生书签。“全部 Siftmark 数据”要求预览并输入确认短语。卸载通常会删除扩展本地数据；需在卸载前导出备份。

## 诊断与事件报告

没有自动诊断上传。复现问题时应使用本地夹具，提供浏览器版本、扩展版本、脱敏错误和最小步骤。不要提交 API Key、Authorization Header、完整网页正文、含密钥备份或个人书签数据库。
