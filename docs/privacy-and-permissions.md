# 权限与隐私

## 隐私摘要

Siftmark 没有账号、遥测、崩溃上报、使用分析或自建服务端。数据默认保存在本机；启用模型时，最小化内容发送至所选 Endpoint。启用 WebDAV 全量同步时，业务数据和模型 API Key 以独立口令加密后发送到用户指定服务器；Windows 更新器会访问 GitHub 稳定版。

## Manifest 权限

| 权限            | 必需性       | 用途与降级                                                                     |
| --------------- | ------------ | ------------------------------------------------------------------------------ |
| `bookmarks`     | 必需         | 读取/创建/修改/移动原生书签，作为唯一事实源；无此权限产品核心不可用            |
| `downloads`     | 必需         | 导出整理前的 HTML，并确认下载完成；失败或取消时不启动整理                      |
| `storage`       | 必需         | 使用 `chrome.storage.local` 保存设置、引导、模型档案和 API Key                 |
| `tabs`          | 必需         | 读取当前/窗口标签页、批量保存、确认活动页及捕获当前可见页面                    |
| `nativeMessaging` | 必需声明 | 与用户一次性安装的 Windows 更新器通信，仅替换绑定的扩展目录 |
| `scripting`     | 必需声明     | 在用户获准的网页上下文运行 Siftmark 打包脚本，支持按需采集；不执行远程代码     |
| `contextMenus`  | 必需         | 注册保存页面、链接、选中文本和打开管理器入口                                   |
| `alarms`        | 必需         | 周期唤醒任务、回收站清理和用户启用的健康检查                                   |
| `idle`          | 必需         | 用户启用睡眠回顾后判断浏览器空闲/锁定；不记录键盘、鼠标或访问内容              |
| `sidePanel`     | 必需         | 显示收藏方案、风险原因和与 Agent 的持续对话                                    |
| `<all_urls>`    | 必需主机权限 | 内容脚本覆盖 HTTP/HTTPS 页面、按需采集/截图，并直接访问用户配置的模型 Endpoint |
| `notifications` | 可选         | 用户开启后台汇总通知时才请求；拒绝后使用应用内通知                             |

快捷命令由 manifest `commands` 声明，不是独立权限。`<all_urls>` 是安装时提示的必需主机权限，扩展自身无法在安装提示出现前展示页面，因此 README 同时提前解释其用途。

撤销特定网站访问后，本地书签树、详情编辑、规则、本地搜索、导入导出和重置仍可用；该网站的正文分析、内容脚本和缩略图不可用。Chrome/Edge 对必需主机权限的撤销方式与行为可能随版本变化。

## 本地存储

- 原生书签：`chrome.bookmarks`。
- 模型档案与 API Key：本机保存于 `chrome.storage.local`，不使用 `chrome.storage.sync`；用户启用 WebDAV 后包含在加密同步数据中。
- 全量整理检查点：`chrome.storage.local` 保存任务书签 ID、各批次的主题和归属结果、分类树、错误摘要及输入校验摘要，用于失败后续跑；不保存完整提示词、隐藏推理或原始响应。
- 元数据、缩略图、任务、操作、索引、通知、用量、收藏会话、偏好和恢复点：扩展 IndexedDB。
- API Key 在浏览器扩展存储中是本地原值，不具备系统钥匙串、TPM 或操作系统账户级加密保证。能读取解锁浏览器配置或控制扩展进程的主体可能获取它。

设置列表只显示掩码；日志和诊断不得输出认证 Header 或 Key。普通备份删除 Key；完整密钥备份必须由用户密码使用 AES-256-GCM 加密。

## WebDAV 与自动更新

全量同步上传书签、笔记、业务配置、模型密钥、学习记录与业务历史的 AES-256-GCM 密文。WebDAV 应用密码和独立加密口令只保存在当前浏览器会话；设备授权不随同步开启。服务端强 ETag 与条件写入必须通过验证；本机变更先预览、备份并确认。断开不会删除云端密文，清空本机数据也不保证云端文件已删除。

Windows 原生消息宿主仅允许安装时指定的扩展 ID 调用，只操作绑定目录；不开放网络监听端口。它向 `zxbdzh/Siftmark` 的 GitHub 稳定版检查、下载安装包与 SHA-256 校验文件；没有遥测。完整使用与限制见 [WebDAV 与自动更新](webdav-and-updates.md)。
## 模型数据流

触发收藏 Agent 后，Siftmark 可能向已启用档案发送：页面标题、已移除认证信息/查询参数/片段的 URL、当前文件夹路径、描述、最多 6,000 字符的正文片段、最多 24 个候选目录、最多 5 个相关书签的脱敏 URL/摘要，以及用户填写的附加规则或本次调整指令。

联网搜索与页面识图默认开启并可分别关闭。页面识图只发送触发收藏时当前可见区域的临时 JPEG；登录、支付、密码、内网和已屏蔽域名页面禁止截图。

单条收藏不会发送完整书签库、URL 查询参数、完整私密笔记或与当前收藏无关的会话。模型只返回结构化方案；移动、改名、目录创建、重复合并和撤销均由本地执行器完成。

点击“备份并整理全部”时，先下载包含整理前全部目录和链接的本地 Netscape HTML；下载失败或取消时不分析、不改动。备份成功后，全部可整理书签的 ID、标题和脱敏网址会分批发送至本次选定的模型 Endpoint，用于生成统一分类树和完整归属；这不是单条收藏的局部上下文，不读取网页正文，不发送原目录、私密笔记或健康记录。归档、回收站和非 HTTP/HTTPS 链接仅进入备份，不参与分析。

完整计划校验通过后，页面显示分类树、各类数量、预计新增目录和移动数量，等待用户整批确认。确认后才在书签栏创建或复用最多三级目录并移动；取消时不创建目录、不移动书签，但已发出的模型请求与额度消耗无法撤回。重复运行时，名称不同的分类可能新增目录；旧目录（包括空目录）不自动删除。任务固定本次模型配置副本，不修改模型档案或全局默认。

整理期间需保持管理器页面打开；隐藏过程窗口不停止任务，关闭管理器会中断后续处理。备份是恢复依据，不是自动撤销；已完成的移动和创建会保留。单条失败或并发修改会保留当前书签状态，不删除或重新创建该书签。

发出前在本地替换常见 API Key、JWT、Bearer Token、密码字段、邮箱和中国大陆手机号。正文被标记为不可信数据，不能改变系统指令、Schema、Endpoint 或权限。

正文只在当前请求内存中存在，请求结束即丢弃；不写入 IndexedDB、storage、日志或备份。Siftmark 不控制第三方模型服务商的日志、训练、地域和保留政策，用户应自行审阅供应商条款。

Embedding 只应使用标题、域名、文件夹、标签和摘要等索引文档，不发送原始正文或完整用户笔记。向量留在本地 IndexedDB，并按档案版本隔离。

Agent 本地学习默认关闭，必须单独授权。开启后仅记录 Siftmark 内的收藏确认、拒绝、撤销、手动分类调整和检索后选择；只保留域名、书签/目录引用、查询分词和结果，不采集网页正文或其他网站的浏览行为。短期证据、本地经验及其来源记录不发送给模型；旧的模型睡眠回顾入口改为本地复盘，不消耗模型额度。分类模型请求仍沿用上文的数据边界，经验只在本地调整候选顺序和最终待确认方案。

## 页面与缩略图

密码输入页、支付页、浏览器内部页、受限协议、内网页面和用户黑名单可阻止正文或截图。截图仅捕获用户当前可见区域，最长边不超过 1,280px，转为本地 WebP；失败不阻止保存。缩略图不后台刷新，默认不进入备份。

Siftmark 不调用第三方 Favicon 服务、远程字体、远程动画、CDN 或分析脚本。字体、图标和 Lottie 均随扩展打包。

## 通知、统计与无痕

系统通知只显示任务类型、状态和数量，不显示书签标题、URL、正文或详细错误。应用内通知详情只存在于扩展本地数据库。

访问统计默认关闭；启用后保存本地次数、最近访问和 90 天日桶，不发送给模型或 Siftmark 服务。

manifest 使用 `incognito: spanning`。默认未获得无痕授权；用户必须在扩展详情页显式开启。开启后无痕和普通窗口共享原生书签与扩展数据，不保存无痕来源标记，因此不要把该功能当作隔离容器。

## 保留与删除

- 通知：30 天或最多 500 条。
- AI 用量：90 天或最多 1,000 条。
- 访问日桶：最近 90 天。
- 回收站：默认 30 天后清理；特殊文件夹未绑定时任务暂停。
- 全量整理检查点：失败或关闭页面后保留以便续跑；成功完成或取消方案后清除。续跑会重新备份，并核对当前输入，变更的批次重新分析。
- 收藏会话：普通待处理状态在 7 天后转为过期；可重试失败继续保留。允许、拒绝、撤销或过期不会自动删除消息，完整记录保存在本机 IndexedDB 供 Agent 历史查看。设置中的“Agent 记录”可删除单条已结束记录，Popup 可清空全部已结束记录；“全部 Siftmark 数据”重置或卸载扩展时通常也会清除。删除会话记录不同时删除已学习的归类偏好。
- 收藏固定规则：只有用户明确表达未来意图时保存，可在设置中查看和删除；不受清空学习数据影响。
- 学习证据与经验：短期证据最多 500 条，保留 30 天；至少两个不同书签的一致明确反馈才形成长期经验，90 天未更新停止采用。冲突、无效目录、过期经验不参与后续建议。暂停后不积累也不采用经验；可纠正、删除或清空。删除保留仅用于阻止旧证据重建的水位，清空则删除这些水位并推进授权时间边界；均不修改原生书签。
- 搜索索引和缩略图可随时单独清理并重建/重新捕获。

设置中的分级重置只删除 Siftmark 扩展数据，永不删除原生书签。“全部 Siftmark 数据”要求预览并输入确认短语。卸载通常会删除扩展本地数据；需在卸载前导出备份。

## 诊断与事件报告

没有自动诊断上传。复现问题时应使用本地夹具，提供浏览器版本、扩展版本、脱敏错误和最小步骤。不要提交 API Key、Authorization Header、完整网页正文、含密钥备份或个人书签数据库。
