## 数据集与方法

- 固定种子：`20260808`。
- 原生 Chromium 书签：200 个文件夹、10,000 条书签。
- 内容覆盖中英文标题、确定性重复 URL、健康状态、标签、摘要、笔记和 AI 置信度。
- 所有 URL 使用映射到本机的 `*.siftmark.test` 域名，不依赖外网或付费模型。
- 书签通过 `chrome.bookmarks.create` 写入，元数据通过 IndexedDB 单事务写入。
- 扩展从 `.output/chrome-mv3` 以开发者模式加载，性能用例单 worker 串行执行。
- JS 堆来自管理器页面 CDP `Performance.getMetrics` 的 `JSHeapUsedSize`，不是浏览器总内存或峰值内存。

## 任务恢复结果

| 观察项 | 门槛 | 实测 | 结果 |
| --- | ---: | ---: | --- |
| 排队并恢复的本地任务 | `1,000` | 1,000 | 通过 |
| 重启后进入预期终态 | 30 秒内全部完成恢复 | 6,901 ms | 通过 |
| 终态分布 | 全部为 `paused` | `paused: 1,000` | 通过 |
| 任务 ID | 无丢失、无重复 | 1,000 个唯一 ID | 通过 |
| 幂等键 | 无丢失、无重复且重启前后集合相同 | 1,000 个唯一键，集合相同 | 通过 |

恢复夹具使用 `purge-recycle-bin` 本地幂等任务。测试环境未绑定回收站，因此 Service Worker 重启后，任务重新排队并执行到设计规定的 `paused` 终态；`unknown`、`failed`、`cancelled` 和 `succeeded` 均为 0。
